# Cursor configuration

- **Agents** — `agents/*.md` (designer, architect, verifier, …)
- **Rules** — `rules/*.mdc` (always-apply and workflow)
- **Skills** — Optional deep guidance. This repo ships minimal stubs under `skills/`; you can copy full skills from [game-collection-ts](https://github.com/) `.cursor/skills/` for clean-code, typescript, performance, playwright-cli, etc.

Invoke agents via Cursor **Task** / subagents per project convention.
